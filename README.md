# tuis-network-tool-mac
東京情報大学(TUIS)の学内ネットワークドライブの割り当てとWebプリントをMacで簡単に行うためのツールです。
公式のものはWindows以外で動かなかったため同梱されていたコードを元にMac版を作成。
自己責任で利用してください。
NASの割り当てをするだけのプログラムです。
プリントはWeb版を使用してください。 
10.10（Yosemite）以降で問題なく動作するはずです。
